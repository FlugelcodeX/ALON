ALON 🌊

A self-initiated web project exploring Philippine identity, visual storytelling, and modern digital design.

📌 Project Overview

ALON is a personal project created to experiment with branding, UI/UX design, and front-end development while building a digital experience inspired by the Philippines.

Unlike client projects, ALON was created independently from concept to implementation, allowing me to freely explore the visual direction, interactions, and overall user experience.

🎯 Project Goals

The project was created to:

Experiment with a unique visual identity
Improve my UI/UX design skills
Explore interactive web experiences
Practice responsive front-end development
Create a project based on my own creative direction
Combine design, storytelling, and development into one experience
💡 Concept

ALON revolves around the idea of waves and movement.

The design uses this concept to create a visual experience that feels fluid, modern, and connected to the Philippine environment and culture.

Rather than following an existing client brief, the visual direction and functionality were developed from my own concept and experimentation.
